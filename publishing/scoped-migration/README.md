## 怎么迁移

```sh
dsh plugin --profile <你的 profile> add dsh-panel-pins
```

然后在**旧版**设置页（设置 → 面板收纳）里「导出与导入」把配置复制出来，到**新版**里导入。两个包名共用同一份 `localStorage` 前缀 `dsh-panel-pins:`，配置格式通用。

> 同一 profile 里两个包名**不能并存**（会双重注册设置分区）——先移除旧的，再装新的：
>
> ```sh
> dsh plugin --profile <你的 profile> remove @qdnbd/dsh-panel-pins
> ```

裸名包 `dsh-panel-pins` 是唯一持续更新的包，兼容 `DSH ≥ 0.2.0-rc.1` + `Node ≥ 20`。
